Stop Bar Assignment System

Enter the stand number and aircraft type or registration to find the assigned stop bar.

QAIA-COO-OPS-AIR-MAN-001-10
p. 116–260

1 Select aircraft & stand details

2 All stop bars for this stand

3 ICAO Aircraft Type Reference (offline)

When a type is not explicitly listed in the stand's guide, the system estimates the stop bar based on ICAO Aircraft Code, matching it to the closest type group sharing the same code at that stand. The system also supports registration lookup and automatic online search for unlisted aircraft.

This tool was built specifically for RJ AIRLINES — for internal use only, and is not a substitute for the official ground operations manual QAIA-COO-OPS-AIR-MAN-001-10.
